### How to run the BAT file

1. Open Notepad.
2. Paste the BAT code above.
3. Click **File → Save As**.
4. Name the file `Download-ZOLIXRECORD.bat`.
5. Select **All Files** as the file type.
6. Double-click the saved file to download the application.
