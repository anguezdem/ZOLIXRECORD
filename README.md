## 📥 Download & Installation

### Method 1 — Download from GitHub

1. Open the [ZOLIXRECORD Releases page](https://github.com/anguezdem/ZOLIXRECORD/releases/latest).
2. Find the latest release.
3. Open the **Assets** section.
4. Download the `.exe` file.
5. Run the downloaded application and follow any instructions displayed.

### Method 2 — Download using Windows CMD

You can download the application directly using Windows Command Prompt.

**Step 1:** Open CMD by pressing `Win + R`, typing `cmd`, and pressing Enter.

**Step 2:** Run the following command:

```cmd
curl -fL -o ZOLIXRECORD.exe "https://github.com/anguezdem/ZOLIXRECORD/releases/latest/download/ZOLIXRECORD.exe"
```

**Step 3:** Run the downloaded file from the directory where it was saved:

```cmd
ZOLIXRECORD.exe
```

**Note:** The download command works only if the release contains a file named exactly `ZOLIXRECORD.exe`. If your uploaded file has a different name, update the command accordingly.

Only run executable files from sources you trust.
