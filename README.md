## 📥 Download

### Using GitHub
Download the latest version from the [Releases page](https://github.com/anguezdem/ZOLIXRECORD/releases/latest).

### Using Windows CMD

Open CMD and run:

```cmd
curl -fL -o ZOLIXRECORD.exe "https://github.com/anguezdem/ZOLIXRECORD/releases/latest/download/ZOLIXRECORD.exe"
```

The command requires the release asset to be named `ZOLIXRECORD.exe`.
